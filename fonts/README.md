# Google Sans Flex

A web version of [Google Sans Flex](https://github.com/google/fonts/tree/main/ofl/googlesansflex) for Folio Reader: Latin characters only, with these variable axes: wght, ROND.

It is made by `.github/workflows/add-font.yml` and is licensed under the SIL Open Font License 1.1 (see `OFL.txt`).
